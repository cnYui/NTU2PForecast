随机读出能不能让脚自己迈步

目标是去掉主线里的落脚规划层（那段手写规则代码），让模型自己学会脚踩地、一步一步走。前两轮把落脚写进训练损失后，脚不再跟着骨盆整体平移，但不迈步。当时我猜是确定性读出把迈步时机平均掉了，所以这一轮换成随机读出来验证。

结论：不行。10 个配置按预登记全部"无效"，我上一轮的猜测也错了。

换成随机读出后，带落脚损失的模型步数还是 0.86–1.20，几乎不随随机程度变化。问题不在读出：落脚损失把脚速整体缩小了，支撑脚停不到 0，摆动脚也迈得慢，看上去就是在"慢挪"。左右交替的节奏其实一直都有。主线不变，仍是 BR + 落脚规划层。

三步路线

  1. FS / FC：锁脚写进损失

    FS 加大"真实着地帧上脚别动"的权重；FC 加着地概率头，按自己预测的着地概率锁脚。

    滑行帧比 .199 → .056 / .067，但步数 1.39 → 1.21 / 0.88，mpjpe +1.4% / +1.2%。无效。

  2. FH / FHS：只在高噪声段约束脚

    落脚项只加在采样的高噪声段；FHS 再加"该摆动时脚要迈出去"的摆动监督。

    精度恢复（FHS −0.2%），滑行 .065，但步数 0.92 / 0.95。无效。当时判断问题在读出。

  3. 本轮：随机读出 + 已有落脚损失

    不训练。把前两轮的 4 个权重和主线 BR 换成随机读出重新评价，看单个随机样本能不能自己定下迈步时机。

    10 个配置全部无效，上一步的判断被否定。

这一轮做了什么

两种读出的区别：扩散模型生成未来动作时，从一个起点出发，用 20 步 Heun 积分走到结果。主线的 ode0 从噪声中心 z = 0 出发，每次输出都一样，接近各种可能未来的平均。随机读出从 τ·ε 出发（ε 是标准高斯噪声），每个采样种子给出一条不同的具体未来；τ 越大越随机。

5 个权重BR、FS、FC、FH、FHS，都是已有的 10000 步 EMA 终点
τ = 0.3 / 0.5τ = 1 已知单样本 mpjpe +27%，不再试
3 个采样种子2718 / 2719 / 2720，判定用均值
30 次评价不加规划层，不训练，共约 10 分钟

判定规则在看结果前写好，与前两轮相同，都和 BR ode0 不加规划比：可替代规划层要求滑行帧比 ≤ .06 且步数 ≥ 1.60；部分有效要求滑行 ≤ .10 且步数 ≥ 1.39；护栏任一不过即无效（mpjpe ≤ 1.01×、xyz_mse ≤ 1.02×、jerk ≤ 24.5、穿地、骨长、四肢摆动、接触前超额后退 ≤ 1.1×、漏接触 ≤ 1.1×）。另外预先规定：如果某个配置只差精度护栏，单独记为"步态达标、精度未过"，交给你决定。本轮没有出现这种情况。

为什么随机读出没用

−38%带落脚损失后，同一窗口换不同随机种子，脚相对骨盆位置的差异变小（BR τ0.3 .0332 → FC/FH/FHS .020–.021）；骨盆位置的差异几乎不变。腿对噪声的响应被压低了。
2.22 步真实动作经过同样的 11 阶 DCT 编解码后仍有 2.22 步、滑行帧比 .045。表示本身能表达迈步，瓶颈不在这里。
0.95 步FHS 的步数。步数指标数的是"左右踝前后交替分离"的次数，带滞回阈值；步幅变小就数不到。滑行帧比只看"脚速 ≈ 骨盆速度"，对慢挪不敏感。

视频对照

每段视频从左到右 6 格，与视频上方的标签一一对齐，下面先说明每格是什么。③④⑤ 的随机读出都用采样种子 2718。灰色细线是真实动作，地面上的点是脚踝轨迹：分开的点是迈步，连续的线是滑行或慢挪。播放速度是半速。

① 真实动作

数据集里这两个人接下来 2.5 秒真正做的动作，是评分的标准答案。

② 主线：BR + 规划层

现在采用的方案。BR 是扩散主线模型（之前训练好的）；读出用 ode0，即确定性读出；最后再用落脚规划层（手写规则）把脚钉在地上、按步子抬起。这就是想用训练替代掉的那一版。

③ BR 随机

和 ② 是同一个 BR 模型，没有任何落脚损失；去掉规划层，读出换成随机读出（τ = 0.3）。用来看"只换读出方式"有没有用。

④ FS 随机

第 1 轮训练的模型 FS：在 BR 的基础上加大"真实着地帧上脚别动"的损失。去掉规划层，用随机读出（τ = 0.3）。

⑤ FHS 随机

第 2 轮训练的模型 FHS，也是最近一次训练的：着地概率头 + 按概率锁脚 + 摆动监督，只加在高噪声段。去掉规划层，用随机读出（τ = 0.3）。

⑥ FHS 确定

和 ⑤ 是同一个 FHS 模型，读出换回确定性的 ode0（第 2 轮当时评价的就是这一格）。⑤ 和 ⑥ 对比，看随机读出对同一个模型的影响。

标签下方的"误差"：这一个案例的 mpjpe，即两个人 55 个关节在未来 50 帧上的平均位置误差，单位是米，越小越好。.175 就是平均差 17.5 厘米。绿色是这一例误差最低的一格。本轮（随机读出）没有训练新模型，④⑤⑥ 用的都是前两轮训练好的权重。视频画面里自带的英文小字和上方标签一一对应：mainline = ②，tau0.3 = 随机读出，ode0 = 确定读出，no planner = 去掉规划层。

名字里的字母：BR = 扩散主线（B 是 11 阶 DCT 带限表示，R 是高噪声段的配方分支）；F 开头的都是在 BR 上加了落脚损失的版本，FS 是加强锁脚（skate），FHS 的 H 表示只加在高噪声段（high noise），末尾的 S 表示加了摆动监督（swing）。

真正缺的是"支撑脚停到 0、摆动脚快速迈出"的形状。逐帧压脚速的损失只能把脚速整体缩小，换哪种读出都一样。

我推荐

可微落脚门，端到端训练

模型输出每只脚的着地概率。解码时，着地的脚速度置 0，没着地的脚按预测速度积分，再用可微两骨 IK 重算膝盖；主损失直接算在这个输出上，着地概率用真实着地标签监督。着地时机和迈步速度都由模型学，不再有"漂移超过 0.16 m 才抬脚"这类手写规则。

风险：着地概率如果被平均成 0.5 左右，又会退化成慢挪。训练时用直通估计，推理时用硬门。每个候选约 2–3 小时训练，开始前先写预登记。

先做 oracle 诊断

把真实着地序列作为条件喂给 FHS 重新训练，看"知道相位以后，现有损失能不能教出停—走—停"。能教出来，说明瓶颈是相位不确定，下一步做着地序列生成器；教不出来，说明结构上需要落脚门。

它更便宜，但只是诊断，不能直接替代规划层。
