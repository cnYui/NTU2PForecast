STG 去噪器内部

去噪器有两路输入。一路是 120 个 token，装着"谁、哪个部位、哪 5 帧、现在是什么样"；另一路是一个 64 维的条件向量 c，装着"现在是第几步（噪声时刻 t）、做什么动作、是 A 还是 B"。c 不变成 token，而是在每一层通过 adaLN 去调制 token。下面按数据流的顺序逐段展开，所有形状和参数量都取自代码和主线 BR 的 seed0 权重。

总览：两条路

条件 c 怎么来：t → 正弦编码 → MLP → + 动作、角色 → SiLU

  1. 噪声时刻 t。每个样本一个标量，\(t\in[0,1]\)，0 是纯噪声端，1 是干净端。采样循环里按 \(t_i=i/20\) 递增，同一批样本用同一个 t。
  2. 正弦编码（无参数）。把一个数展开成 64 维，让网络容易区分相近的 t。先放大 1000 倍（和常见扩散实现的步数量级一致），再用 32 个几何间隔的频率：
    \[ \omega_i = 10000^{-i/32},\quad i=0,\dots,31,\qquad \mathrm{PE}(t)=\big[\cos(1000t\,\omega_0),\dots,\cos(1000t\,\omega_{31}),\ \sin(1000t\,\omega_0),\dots,\sin(1000t\,\omega_{31})\big] \]
    高频分量（\(i\) 小）对 t 的微小变化很敏感，低频分量（\(i\) 大）缓慢变化，合起来像一把多刻度的尺子。
  3. MLP（可学习）。\(\tau=W_2\,\mathrm{SiLU}(W_1\,\mathrm{PE}(t)+b_1)+b_2\)，\(W_1,W_2\in\mathbb R^{64\times64}\)，共 8,320 个参数。它把固定的编码变成网络自己需要的"时刻特征"。
  4. 加上动作和角色。两张查找表：动作 \(E_{\text{act}}\in\mathbb R^{26\times64}\)，角色 \(E_{\text{role}}\in\mathbb R^{2\times64}\)。同一个样本里 A 和 B 的动作、时刻相同，只有角色不同，所以得到两份：
    \[ c_p=\mathrm{SiLU}\big(E_{\text{act}}[a]+E_{\text{role}}[p]+\tau\big),\qquad p\in\{A,B\},\quad c\in\mathbb R^{B\times2\times64} \]
    训练后三者的量级相近：\(\lVert\tau\rVert\) 在 t=0 时约 9.3、t=1 时约 17.7；动作嵌入约 8.1，角色嵌入约 8.0。
  5. c 去哪里。不拼进 token，而是送进每一层的 adaLN 线性层（第 4 节）、末层 adaLN（第 6 节），以及腿流的条件输入。
t = 0.35

左 32 根是 cos，右 32 根是 sin；从左到右频率由高到低。t 只走 0.05 一步时，左侧高频分量就已经大幅变化，右侧低频分量几乎不动。

token 怎么来：几项相加

每个 token 是"某人 p、某部位 g、某 5 帧块 b"。先把这块的坐标拉平成向量 \(v_{p,g,b}\)（未来块还拼上上一步 \(\hat x\) 解码出的同一块，观测块复制自己凑长度），再加 6 项：

\[ h^{(0)}_{p,g,b}=\underbrace{W^{(g)}_2W^{(g)}_1 v_{p,g,b}}_{\text{部位瓶颈投影}}+e^{\text{part}}_g+e^{\text{block}}_b+e^{\text{obs/fut}}_{[b\le2]}+e^{\text{role}}_p+W_s\big[\text{几何}_p;\ \text{末帧姿态}_p\big] \]
项形状作用
部位瓶颈投影v → 128 → 192，每个部位一套躯干 v 长 5×11×3×2 = 330，手臂 150，腿 120；先压到 128 再升到 192
部位嵌入 part_pos[5, 192]告诉 token 它是躯干、左臂、右臂、左腿还是右腿
时间块嵌入 patch_pos[12, 192]第几个 5 帧块
观测/未来标记 obs_flag[2, 192]前 2 块是已知观测，后 10 块是要生成的未来
角色嵌入 role_pos[2, 192]A（施动）还是 B（受动）
静态几何 static_proj171 → 192两人相对几何 6 维 + 本人末帧姿态 55×3 = 165 维，加到这个人的全部 60 个 token 上

注意 t、动作标签不在这里加。它们只走条件 c 那一路。

一层里面：adaLN-Zero 怎么用 c

公式

\[ (\beta_1,\gamma_1,\alpha_1,\beta_2,\gamma_2,\alpha_2)=W_{\text{ada}}\,c_p+b_{\text{ada}},\qquad W_{\text{ada}}\in\mathbb R^{1152\times64} \]
\[ \mathrm{RMS}(h)=\frac{h}{\sqrt{\tfrac1{192}\sum_j h_j^2+10^{-6}}},\qquad u=\mathrm{RMS}(h)\odot(1+\gamma_1)+\beta_1 \]
\[ Q,K,V=W_{qkv}u,\quad Q\leftarrow\mathrm{RMS}(Q)\odot w_q,\ K\leftarrow\mathrm{RMS}(K)\odot w_k \quad(\text{每头 48 维}) \]
\[ A=\mathrm{softmax}\!\Big(\frac{QK^\top}{\sqrt{48}}+B^{\text{part}}_{s_{ij}}[g_i,g_j]+B^{\text{time}}_{s_{ij}}[b_j-b_i]\Big),\qquad h\leftarrow h+\alpha_1\odot W_o(AV) \]
\[ u_2=\mathrm{RMS}(h)\odot(1+\gamma_2)+\beta_2,\qquad h\leftarrow h+\alpha_2\odot W_2\big(\mathrm{SiLU}(W_1u_2)\odot W_3u_2\big) \]
  • 三种参数各管什么。\(\gamma\)（scale）放大或缩小每个通道，\(\beta\)（shift）整体平移，\(\alpha\)（gate）决定这个子层的结果加回去多少。它们都由 c 算出来，所以"第几步、什么动作、A 还是 B"直接改变每一层怎么处理 token。
  • 为什么叫 Zero。\(W_{\text{ada}}\) 和 \(b_{\text{ada}}\) 初始化为 0，训练开始时 \(\gamma=\beta=\alpha=0\)，每个子层只剩 \(h\leftarrow h+0\)，整层等于恒等映射。网络从"什么都不改"开始学，深层训练更稳；输出头也是零初始化，所以刚开始的预测就是"保持末帧不动"。
  • RMSNorm 没有自己的缩放参数。缩放和平移全部交给 \(\gamma,\beta\)，也就是全部由条件决定。
  • 两种注意力偏置。\(B^{\text{part}}\in\mathbb R^{4\times2\times5\times5}\)：4 个头 × 同人/跨人 × 查询部位 × 被看部位；\(B^{\text{time}}\in\mathbb R^{4\times2\times23}\)：相隔 −11 到 +11 个时间块。它们不依赖 c，6 层共用同一份，零初始化。主线不加因果掩码，所有 token 两两可见。
  • SwiGLU。\(W_1u_2\) 过 SiLU 后当"门"，逐元素乘上 \(W_3u_2\)，再由 \(W_2\) 压回 192 维。内层宽度 \(\lfloor192\times4\times\tfrac23\rfloor=512\)。

训练后：门控 α 随 t 怎么变

用主线 BR 的 seed0 权重实算：动作固定为"推人"，把 t 从 0 扫到 1，看每一层两个门控的平均大小 \(\overline{|\alpha|}\)（192 个通道取绝对值平均）。这说明 c 确实在改变网络的行为：同一层在不同 t 下"用多少力"不一样。

角色
注意力门控 \(\overline{|\alpha_1|}\)
前馈门控 \(\overline{|\alpha_2|}\)

例如第 2 层的前馈门控从 t=0 的 0.16 增大到 t=1 的 0.36：越接近干净端，这一层对 token 的改写越强；第 2–4 层的注意力门控则随 t 减小。这是训练后的现象描述，不代表设计时有意如此。

输出：从 token 回到 x̂

  1. 末层 adaLN。\(W_{\text{final}}\in\mathbb R^{384\times64}\) 给出 \((\beta,\gamma)\)，\(\tilde h=\mathrm{RMS}(h)\odot(1+\gamma)+\beta\)。这里只有平移和缩放，没有门控。
  2. 部位输出头（零初始化）。只取未来 10 个时间块的 token，每个部位一个线性层 \(192\to5\cdot n_g\cdot3\)，得到 50 帧时域残差 \(\tilde\Delta\in\mathbb R^{50\times2\times29\times3}\)。
  3. 投回 DCT。\(\hat c=\Psi^\top\tilde\Delta\)，再除以尺度 \(\sigma_r=0.1406,\ \sigma_l=0.1884\)，得到 \(\hat x\)。11 阶以外的成分在这一步被丢掉。
  4. 腿流替换腿。MLP（宽 512）读观测腿部运动、骨盆轨迹、主干的 root 估计、token 平均表示（截断梯度）、条件 c（截断梯度）、带噪声的腿系数和上一步的腿估计，输出 8 个腿关节的系数，替换 \(\hat x\) 中对应的行。
