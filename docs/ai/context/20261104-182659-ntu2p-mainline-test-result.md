## 解读

- **精度收益在 test 上基本消失**：H-val 上主线 mpjpe −2.0%（BR:ode0 −2.24%），test 上只有 −0.45%（BR:ode0 −0.81%）。差距约 1.4–1.6 个百分点，与 `20260926-162912-ntu2p-subject-holdout-val-result.md` 记录的 H-val 估计误差（约 1.4 个百分点）同量级。不能把主线描述为"精度显著提升"。
- **确定的改进是腿**：滑行、步数、穿地在 test 上与 H-val 一致地大幅改善，来自落脚规划层。
- **变差**：xyz_mse（选定单一未来、偶尔选错走向）、四肢摆动（ode0 接近平均动作）、交互时序与漏接触。这些与 H-val 上看到的一致。
- 两种读出（带/不带规划层）的取舍已在 H-val 决定，这里只报告，不据此再选。
