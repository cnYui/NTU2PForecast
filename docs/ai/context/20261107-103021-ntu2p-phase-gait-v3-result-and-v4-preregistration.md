- **判定：无效（护栏未过）。** 只有 mpjpe 一条没过：1.0053×，上限 1.005×，差 0.03 个百分点。jerk、穿地、xyz_mse、摆动、超额后退、漏接触全部过，步态达到"可替代"级。按规则不放宽。
- **观测锚定的效果**：jerk 26.3 → 21.0；腿误差多出的部分在第 1–5 帧从 +2.0 cm 降到 +0.7 cm。
- **剩下的 mpjpe 代价来自迈步本身**：
  - 腿误差在各时段高 0.6–1.1 cm；
  - 非步行人的踝相对骨盆路程：GT .77 m（含抖动）、BR .20、PGait .44；

  - 未来时机不确定时，动得多的预测 L2 误差更大。逐窗看，247 个窗口中 PGait 只有 54 个比 BR 好。

## v4：相位预测器加腿部 L2（经冻结解码器）

- 改动只有一处：相位预测器训练时，加"解码后未来腿关节与 GT 的平均距离"损失。解码器保持冻结，所以这一项只能改相位、频率、振幅、偏置。时机不确定时，它会让预测器少迈一点、迈小一点。这是用精度换自然度的显式权衡。
- 自洽支撑项保留，用来抵消"不迈但骨盆在走"导致的滑行。
- 两档并行：**v4a 权重 1.0**，**v4b 权重 3.0**。其余与 v3 完全相同。

**选择规则（看结果前固定）**：
1. 两档都按原判定（与 BR:ode0 比，mpjpe ≤ 1.005×，滑行 ≤ .06，步数 ≥ 1.60，护栏全过）。
2. 都可采纳时，取 mpjpe 较低者；都不可采纳则记为负结果，不再加档。
3. 选中者须补 3 seed 复核：模块种子 1/2 分别挂在 BR seed 1/2 上，按 3 seed 均值套用同一判定；再抽帧目视。
4. 原协议 test 只在用户确认后评一次。
