# 跨人腿部时间 Transformer（XL）：设计与预登记

用户 2026-11-05 问"人的腿和别人的腿之间应该也有关系……是不是也可以用时间去进行 transformer 这样的预测"，随后"跑一下看看"。

## 问题

主线 BR 的腿流是每人独立的 MLP，只通过主干的 root 估计与上下文间接知道对方。在腿的预测里显式加入"两人双腿在时间上的跨人注意力"，能否改善 B 随 A 后退/跟随时的步态与交互时机？

## 设计（只加一个模块，其余与 BR 完全相同）

在 `NTU2PJiTFlow._legs` 里，腿流 MLP 输出之后加一个**零初始化的残差修正** `LegCrossTransformer`（`flow_kwargs {"leg_xattn": true}`）：

- **token**：2 人 × 2 条腿 × 12 个 5 帧块 = 48 个。每条腿取骨盆 + 髋/膝/踝/脚 5 个关节，全部转到**场景规范系的绝对位置**（相对观测末帧骨盆中点原点），使两人的腿在同一坐标里可比。观测块用真实观测；未来块拼两份：当前带噪状态 z 解码的轨迹、本次估计（主干 root + 腿流 MLP 的腿）解码的轨迹；观测块复制自己凑长度。每 token 输入 5 帧 × 5 关节 × 3 × 2 = 150 维。
- **嵌入**：Linear 150 → 128，加腿（左/右）、时间块、角色、观测/未来四种可学习嵌入。
- **主体**：2 层与主干相同的 adaLN-Zero Transformer 块（宽 128、4 头、SwiGLU），条件为同一个 c（t + 动作 + 角色）；48 个 token **全连接注意力**，A 的腿与 B 的腿互相可见。
- **输出**：零初始化线性头，读未来 10 块，给出每条腿 4 个关节相对骨盆的 50 帧时域修正 → 转回人物系 → 用编解码器投回 11 阶系数 → 除以尺度 → **加到**腿流 MLP 的输出上。零初始化保证初始时与 BR 的结构完全相同；模块在 fork 出的随机流里初始化，其余参数初始化与 BR 同 seed 一致。
- 参数约 +0.5M。

## 实验

H-val seed0 × 10000 step、EMA 终点，与已有 BR seed0 配对（STG 训练逐运行不确定，单 seed 噪声约 0.8%）。读出：ode0 + 落脚规划（主线完整输出，判定用）；另报 ode0。BR 的同读出复用 `subjval/jointgraph_s0/BR_ode0plan.json`。

## 判定（看结果前固定）

**有增量**（任一成立，且护栏全过）：
- 精度：mpjpe ≤ 0.992 × BR，且 xyz_mse ≤ BR；
- 交互：接触前超额后退 ≤ 0.9 × BR，且漏接触 ≤ BR；
- 腿：滑行帧比 ≤ BR − 0.005 且步数 ≥ BR，且左右交替相关 `gait_sep_corr_f01_10` ≥ BR。

**护栏**：mpjpe ≤ 1.01 × BR；jerk ≤ 24.5；骨长 ≤ 1e-5；穿地 ≤ BR + 0.01；摆动 gate（dct_low ≥ 0.40、dct_mid ≥ 0.10）。

**目视**：#028、#002 推人，#194 跟随，#010 走开，GT | BR | XL 抽帧，看 B 后退时的步态是否与 A 的前进配合、有无新问题。

有增量也只算单 seed 筛选，补 seed1/2 须用户确认；无增量则记负结果、不调参。
