# 细分部位（F13）与骨架邻接图（SK）两个单因子对照：设计与预登记

## 候选（各只改一处，其余与主线 BR 完全相同）

- **F13 只细分部位**：`part_scheme="fine"`（每人 13 个关节组，token 120 → 312），**不加**距离边 `joint_graph`、**不加**跨人因果 `causal_cross`。用来把 G1 的三处改动拆开，单独看"细分"本身。
- **SK 骨架邻接图（GCN 式约束）**：部位仍为 5 组，在 STG 注意力上加**硬邻接掩码**，只允许以下 token 对互相看：
  - 时间：两个 token 相隔不超过 2 个 5 帧块（ST-GCN 式时间邻域；6 层叠加后感受野可覆盖全部 12 块）；
  - 同一人：同一部位，或骨架上相连的部位（躯干 ↔ 左臂/右臂/左腿/右腿；四肢之间不直接相连）；
  - 跨人：只经躯干相连（一方任一部位 ↔ 对方躯干），这是人为指定的跨人边。
  注意力分数、部位对偏置与时间偏置保留，即"在骨架图上做图注意力"。不新增参数，初始化与 BR 同 seed 逐位一致。
