# 落脚融入训练第二版：脚部损失只加在高噪声段 + 摆动监督（预登记）

用户 2026-11-06："试下一版"。上一版（`20261106-193836-ntu2p-foot-planting-in-training-result.md`）FS/FC 不加规划时滑行帧比降到 .056/.067，但步数降到 1.21/0.88、站立占比远高于 GT、精度 +1.2–1.4%：锁脚学会了，迈步没学会。

## 两处改动的理由

1. **脚部损失只加在高噪声段（t ∈ [0.5, 1) 的配方分支），不加在 t = 0 端点。** 端点时状态 z = 0，模型完全不知道下一步何时迈，锁脚只能把脚"冻住"；高噪声段的状态里已带有真实步态的相位，主线 ode0 最后交付的 x̂ 也正来自这一段（最后一步 t = 0.95）。
2. **加摆动监督。** 着地标签之外，GT 处于摆动（非着地）的帧上，预测脚的水平速度要跟 GT 的脚速度一致：教模型"该迈的时候迈出去"，而不只是"该停的时候停住"。归一化常数取 copy-last（脚不动）时的该项值，与其他 copy-last 归一化项同口径。

## 候选（与 BR 只差脚部损失，均带 FC 的着地概率头；评价 ode0 **不加**落脚规划）

- **FH**：着地 BCE 0.1 + 自洽锁脚 1.0，**只在高噪声段**。单独看"换位置"的作用。
- **FHS**：FH + **摆动监督 0.5**（也只在高噪声段）。用户要的完整下一版。

GT 锁脚项保持 BR 的 0.05（两个分支都有），其余全部同 BR。H-val seed0 × 10000 step、EMA 终点，两者并行。

## 判定（看结果前固定，与上一版相同；均与 BR 不加规划比）

- 可替代落脚规划层：滑行帧比 ≤ 0.06，且步数 ≥ 1.60；
- 部分有效：滑行帧比 ≤ 0.10，且步数 ≥ 1.39；
- 否则无效。
- 护栏（任一不过降为无效）：mpjpe ≤ 1.01 × BR；xyz_mse ≤ 1.02 × BR；jerk ≤ 24.5；穿地 ≤ BR + 0.01；骨长 ≤ 1e-5；摆动 gate；超额后退 ≤ 1.1 × BR；漏接触 ≤ 1.1 × BR。
- 另报：站立占比、左右前向速度相关（GT .348 / −.39）。
