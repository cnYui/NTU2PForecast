## 目视（seed0）

选例规则：按 manifest 顺序取前 3 个步行窗（GT 骨盆位移 ≥ 0.5 m），不按结果挑选。视频在 `results/forecasting/ntu120_label/ntu2p_jitflow/original/phase_gait_test/videos/`。

- **#009 迎面走来**：PGait 两人膝盖抬起、交替迈步，红方脚印是分开的点；BR 双腿较直，脚印是连续拖线。误差 .136 vs .139。
- **#010 走开**：BR 红方的脚印是连续拖线，PGait 是分开的点。两者的蓝方走向都偏离 GT，那是主体 root 的问题。误差 .315 vs .313。
- **#002 推人**：误差 .237 vs .234。

## 结论

- test 复现了 H-val 的结论：只靠训练学到的步态模块，就让脚踩实、一步一步走。滑行、步数、交替、穿地都接近 GT，而且没有任何后处理。
- 代价是 mpjpe 比 BR:ode0 高约 0.4–0.5%。
- 是否把它并入主线（代替"BR:ode0 不加后处理"），由用户决定。
- 降低 mpjpe 的方向是主体与步态端到端联合训练，或者给主体更好的走向/意图预测；后者也是 #194、#010 走错方向的根源。
