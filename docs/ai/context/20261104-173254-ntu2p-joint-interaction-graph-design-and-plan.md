# NTU2P 关节级交互图（"碰到之后才躲"）：设计、预登记与计划

## 1. 用户需求

用户 2026-11-04：针对主线的三个局限（四肢摆动偏少、模型选错走向、手没碰到就躲），"通过不同关节之间的图神经网络去做重新的训练……比如我的手和他的肩膀相关性肯定会更强一些，这样他的手碰到别人的肩膀之后，那个别人就会往后躲"。

## 2. 与已做过的图方案的区别（避免重复包装）

- 10-14 C/F 组：在冻结或微调的 FD2 上加掌腕—躯干图纠正器，无增量。
- 10-18 J4：STG 的 5 个粗部位（躯干/两臂/两腿）之间，只给"对方手臂整段 ↔ 本人躯干整段"加一个由手—躯干距离算出的注意力偏置，再加跨人因果掩码；3 seed 与 J3 持平（−3.22% vs −3.30%），交互指标反而变差。
- 本轮的不同：(1) **关节级节点**：部位细分为 13 组，手、肘、肩、胸、头分开，"A 的右手 ↔ B 的左肩"是独立的一条边；(2) **所有跨人关节组对**都有可学习的先验偏置，并都加一项由当前估计算出的**距离边权**（RBF 展开，不只手—躯干）；(3) 新增两项直接针对问题的训练损失（4 节），J4 没有；(4) 底座换成当前主线 BR（带限 + 高 t 配方），读出为 ode0 + 落脚规划层。

诚实的预期：图结构能让"B 的反应与 A 的手的位置挂钩"有机会被学到，但确定性读出仍会平均接触时刻；J4 的负结果说明光加图不够，本轮的主要变化在关节粒度和交互损失上。四肢摆动偏少主要来自 ode0 从噪声中心出发、接近平均动作，图网络不直接解决，另设低温读出单独评价（5 节）。

## 3. 模型：细粒度部位 + 跨人距离边（在 BR 上改，`model/forecasting_ntu2p_jitflow.py`）

- `part_scheme="fine"`：13 个关节组（状态行，均来自 SMPL-X 编号）：骨盆+spine1（0,3）、胸（6,9）、头颈（12,15,22,23,24）、左/右肩带（13,16 / 14,17）、左/右肘（18 / 19）、左/右手（20,25,31 / 21,40,46）、左/右大腿（1,4 / 2,5）、左/右脚（7,10 / 8,11）。token 数 2 人 × 13 组 × 12 个 5 帧块 = 312（原 120）。每组有独立的 patch 嵌入与输出头；腿仍由腿部流替换。
- 部位对偏置 `part_bias[头, 是否跨人, i, j]`（零初始化、可学习）随部位细分自动成为 13×13 的关节组先验，即"手 ↔ 肩"一类的可学习相关性。
- `joint_graph=True`：跨人距离边。用当前估计（自条件 x̂；没有时为 copy-last）解码完整 60 帧，在场景规范系求每个关节组每个 5 帧块的质心；对每个"本人组 i 第 k 块 ↔ 对方组 j 第 k′ 块"的 token 对，取质心距离做 8 个 RBF（中心 0–1.4 m，宽 0.2 m），线性映射到每个注意力头的偏置（零初始化）。同人 token 对不加。
- `causal_cross=True`：本人第 k 块只看对方第 ≤ k 块（"先有接触才有反应"的结构偏置，同 J4）。
- 零初始化保证新模型初始时与等价的细粒度无图模型输出相同；参数量变化主要来自 13 组的嵌入与输出头。

## 4. 训练：交互损失（`train/train_ntu2p_jitflow.py`，施加在端点与高 t 配方两处）

- `contact_curve`：双向"手（腕与掌心两处）→ 对方躯干 6 段"最近距离曲线的 MSE（`utils/ntu2p_contact_graph.contact_distance_loss`）。直接监督"A 的手到达 B 的哪里、什么时候到"。
- `proximity_curve`：两人 22 个身体关节之间最近距离的逐帧曲线与 GT 的 MSE。预测比 GT 更近（走进对方、撞在一起）或更远都会被罚。
- 两项都除以 copy-last 在 train 上的值（与现有配方同口径，`old_scale_starts` 同一批窗口），权重各 1.0。

## 5. 候选与读出

| 代号 | 结构 | 交互损失 |
|---|---|---|
| BR（主线，已有） | 5 部位 | 无 |
| G1 | 13 组 + 跨人距离边 + 跨人因果 | 无 |
| G2 | 同 G1 | contact_curve 1.0 + proximity_curve 1.0 |

读出（全部加落脚规划层）：**ode0**（主线读出，用于判定）；**τ=0.3 单样本**（采样种子 2718，专看四肢摆动，BR 也评）。

H-val seed0 × 10000 step（采样读出在 5000 step 明显偏差，见 BR 结果），EMA 终点。G1、G2 并发训练。

## 6. 预登记判定（H-val seed0，对照 BR:ode0 + 规划层 seed0：excess_antic .0330、漏接触 43、推人接触距离 RMSE .207、mpjpe .16959）

**交互（主目标，全部须满足）**：
- primary_excess_antic ≤ 0.8 × BR（≤ .0264）；
- 漏接触总数（三阈值合计）≤ BR（43）；
- 推人接触距离 RMSE ≤ BR（.207）。

**走向/重叠（主目标）**：新指标"错误重叠帧比"= 预测两人身体最近距离 < 0.10 m 而 GT ≥ 0.30 m 的帧占比（全窗口），须 ≤ BR。

**护栏**：mpjpe ≤ 1.01 × BR；xyz_mse ≤ 1.02 × BR；滑行帧比 ≤ BR + 0.01；步数 ≥ BR − 0.1；jerk ≤ 24.5（1.2 × FD2）；骨长 ≤ 1e-5；穿地 ≤ BR + 0.01。

**目视**：全部 12 个推人窗 + 固定 9 例抽帧；推人案例里 B 的后退须在 A 的手到达之后才开始（以接触—后退曲线图与抽帧共同判断）。

**摆动（次要，τ=0.3 读出单独判定）**：dct_mid ≥ 0.40、mpjpe ≤ 1.01 × 同模型 ode0、jerk ≤ 24.5，且抽帧无抖动。

seed0 满足主目标与护栏的候选补 seed1/2；3 seed 均值仍满足才进入主线（再经用户确认后评 test）。都不满足则如实报告负结果，不调宽门限、不延长训练。

## 7. 实施清单

- 模型：`part_scheme`、`joint_graph` 配置键（默认 coarse/False，旧 checkpoint 行为不变）；`_part_centroids`；`STGDenoiser` 支持任意部位划分与距离边偏置。
- 训练：`--contact_curve_weight`、`--proximity_curve_weight`；copy-last 尺度估计。
- 评价：`--foot_planner` 已有；错误重叠帧比在汇总脚本里由导出数组计算。
- 检查：fine/coarse 前向形状；零初始化时 G1 的距离边偏置为 0；跨人因果掩码下改动对方未来块不影响本人更早块；旧 BR checkpoint 重载逐位一致；两项新损失对 GT 输入为 0。
