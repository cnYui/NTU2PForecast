# 相位步态模块 v1 结果与 v2 预登记

设计与原预登记：`20261107-095645-ntu2p-phase-manifold-gait-design-and-preregistration.md`。

## v1 结果（H-val seed0，挂在 BR seed0 上，模块训练约 4 分钟）

**诊断（只换腿，root 和上半身用 GT）：**

| | 步数 | 滑行帧比 | 站立占比 | 左右前向速度相关 | 腿误差 m |
|---|---:|---:|---:|---:|---:|
| GT | 2.29 | .034 | .348 | −.39 | — |
| S0-1 GT 相位 + GT root | 2.18 | .043 | .351 | −.35 | .050 |
| S0-2 预测相位 + GT root | 2.27 | .037 | .306 | −.26 | .088 |
| BR 的腿接到 GT root（参照） | 1.39 | .317 | .334 | +.10 | .094 |

- S0-1 过了继续条件（步数 ≥ 2.0、滑行 ≤ .06）：相位流形和解码器能表达步态。
- S0-2：用预测相位时腿误差比 BR 的腿还低（.088 vs .094），步态接近 GT。

**S0-3 完整推理（BR:ode0 + 步态模块）**：

| | mpjpe | 滑行帧比 | 步数 | jerk | 穿地 |
|---|---:|---:|---:|---:|---:|
| BR:ode0 | .1691 | .199 | 1.39 | 15.4 | .068 |
| PGait v1 | .1703（+0.7%） | .030 | 2.09 | 29.8 | .092 |

- 判定：**无效（护栏未过）**。mpjpe、jerk、穿地三条没过；步态本身达到"可替代"级。
- 左右前向速度相关 −.22，xyz_mse、四肢摆动、超额后退、漏接触都过。

**原因：**
- **穿地**：穿地帧上 BR 骨盆比 GT 低 9.0 cm（全体均值只低 0.7 cm）。解码器不知道地面位置，腿照常伸直插进地里。
- **jerk**：腿在预测头 3 帧的 jerk 为 438 / 744 / 371，是观测末帧与解码首帧之间的跳变。其余帧腿 jerk 44（BR 10.6；GT 384，含动捕抖动），反映真实迈步更尖锐的形状。
- **mpjpe**：腿误差 .1386 vs BR .1273。S0-2（GT root）比 BR 好，S0-3 变差。相位预测器训练末期损失仍在下降，而且只见过 GT 速度加白噪声，没见过 BR 那种偏平滑的速度。

## v2 改动（全部是训练内的改动，没有规则后处理）

1. **解码器感知地面**：
   - 新增输入：每帧骨盆相对"观测期最低脚高"的高度。
   - 训练增强：一半样本把未来帧的髋和骨盆沿竖直方向降低 0–12 cm（前 5 帧渐入）。被降低的样本只监督踝和脚掌（膝够不到原位置），让解码器学会"髋低了就屈膝，脚仍落在地上"。
   - 新增穿地损失：生成的脚关节低于观测地面的部分取平方。
2. **相位预测器做观测重建**：解码器冻结，用反推到观测帧的相位解码出观测期的腿，与观测到的真实腿比 L2。这样当前相位要能复现当前姿态（分析—合成），同时消除衔接跳变。
3. 相位预测器训练 12000 步（v1 为 6000 步）。

其余结构、超参与判定规则不变：仍与 BR:ode0 不加后处理比，mpjpe ≤ 1.005×、jerk ≤ 24.5、穿地 ≤ BR + .01 等，详见原预登记。v2 只评一次 S0-1/S0-2/S0-3，不按结果回调权重。可采纳后才做 3 seed 和端到端联合训练。
