- 判定：无效（护栏未过）。没过的是 mpjpe（> 1.005×）和 jerk（> 24.5）；穿地已过，而且低于 BR。
- **jerk**：腿在预测第 1–3 帧的 jerk 为 375 / 602 / 298，之后均值 36。全身 jerk 第 1–5 帧均值 131，之后 14.6（BR 13.8）。超标几乎全部来自观测与预测的衔接。观测重建损失把衔接误差降到 2.8 cm，但还没消除。
- **腿误差**：比 BR 多出的部分集中在开头，第 1–5 帧 +2.0 cm、第 6–10 帧 +1.8 cm，之后 +0.6–0.9 cm。不走路的人也比 BR 差（.108 vs .095），说明相位流形对非周期姿态（下蹲、站定、站姿宽度）的细节有损失。步行人只差 .5 cm。

## v3 改动（模型结构与训练，没有后处理）

1. **观测锚定（结构）**：
   - 解码出的骨方向加一个从观测末帧衰减的残差：d(t) = normalize(G(t) + (d_obs − G(t₀))·exp(−(t − t₀)/τ))，τ = 4 帧。
   - 首帧与观测严格连续，再平滑过渡到相位驱动的步态。
   - 这与主体 BR 的"IDCT × ramp 从观测末帧出发"是同一类解码结构。相位预测器在训练中也经过这一层。
2. **解码器以观测末帧腿姿为条件**：6 段骨方向，共 18 维，整窗恒定。让它在不走路时保留观测到的站姿和屈膝。
3. **相位预测器的速度输入模拟主体输出**：
   - 一半样本把 GT 未来骨盆速度截断到 DCT 8 阶（与 BR root 的 8 阶带限一致），并乘以 0.6–1.0 的随机收缩，模拟确定性主体在走向不确定时给出的偏慢、偏平滑速度；
   - 再加 v1/v2 同样的噪声。

**不变的部分**：相位预测器 12000 步、地面感知与穿地损失、判定规则（与 BR:ode0 比，mpjpe ≤ 1.005×、jerk ≤ 24.5 等）。v3 只评一次，不回调。

**后续**：可采纳后补 3 seed（模块种子 0/1/2 分别挂在 BR seed 0/1/2 上）；之后做端到端联合训练，目标是降低 mpjpe。
