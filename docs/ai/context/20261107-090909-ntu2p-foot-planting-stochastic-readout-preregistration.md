# 落脚融入训练第三步：随机读出 + 落脚损失（预登记）

用户 2026-11-07："试随机读出"。前两轮（`20261106-193836-...-in-training-result.md`、`20261106-210627-...-v2-result.md`）的结论：落脚损失在确定性读出 ode0 下只学会"脚不跟着骨盆平移"，学不会迈步（步数 0.88–1.21，GT 2.29），视频里脚在慢慢挪。推测原因是 ode0 从 z = 0 出发，输出接近各种可能未来的平均，迈步时机被平均掉了。

## 假设

单个随机样本（从 τ·噪声出发的同一 Heun 20 步 ODE）自带一组具体的迈步时机，不会被平均掉。再配合落脚损失，就可能在不加规划层的情况下同时做到"脚不漂"和"一步一步迈"。

## 设置（不训练，只评价已有权重）

- **模型**：H-val seed0、10000 step、EMA 终点的 BR、FS、FC、FH、FHS（定义见前两轮预登记）。
- **读出**：`--flow_readout sample --flow_temperature τ`，单样本，τ ∈ {0.3, 0.5}。不再试 τ = 1，因为 BR 在 τ = 1 时单样本 mpjpe 已 +27%。
- **采样种子**：{2718, 2719, 2720}。判定用 3 个种子的均值，同时报告范围。
- **不加落脚规划层。**
- **对照**：
  - BR 同 τ 不加规划：区分"随机读出本身的作用"和"落脚损失的作用"；
  - BR ode0 不加规划：护栏基准，与前两轮相同；
  - BR ode0 + 规划：当前主线，是要替代的目标。

## 判定（看结果前固定）

判定规则与前两轮相同，都和 BR ode0 不加规划比。

**等级：**
- 可替代落脚规划层：滑行帧比 ≤ 0.06，且步数 ≥ 1.60；
- 部分有效：滑行帧比 ≤ 0.10，且步数 ≥ 1.39；
- 否则无效。

**护栏（任一不过即降为无效）：**
- mpjpe ≤ 1.01 × BR；
- xyz_mse ≤ 1.02 × BR；
- jerk ≤ 24.5；
- 穿地 ≤ BR + 0.01；
- 骨长 ≤ 1e-5；
- 摆动 gate；
- 超额后退 ≤ 1.1 × BR；
- 漏接触 ≤ 1.1 × BR。

**补充规则：**
- **步态达标但精度护栏未过**：如果某配置只因 mpjpe 或 xyz_mse 护栏没过而判为无效，单独记为"步态达标、精度未过"。它不采纳，也不由我放宽护栏；是否接受这一精度代价由用户决定。已知 BR 在 τ = 0.3 加规划时 mpjpe 比 ode0 高约 1.7–2.1%，很可能触发这条。
- **归因**：只有当 Fx:τ 的步数和滑行都优于 BR:τ 时，才把改善记在落脚损失上；否则记为随机读出本身的作用。

**另报：** 站立占比、左右前向速度相关、着地帧脚速、dct_mid。

**目视（以视频为准）：**
- 案例：#010 走开、#216 一起搬东西、#194 跟随、#028 推人；
- 并排：GT | BR + 规划 | BR:τ | FHS:τ | 达标最好的候选；
- 只看种子 2718；
- 看脚印是否成簇（迈步），还是连续细线（挪动/滑行）；四肢是否抖动。

单 seed 筛选。即使"可替代"，也须补训练 seed、经用户确认后才去掉规划层。不调权重，不加训练。

**实现：** `scripts/run_ntu2p_footloss_sample.py`，输出到 `results/forecasting/ntu120_label/ntu2p_jitflow/subjval/footloss_sample_s0/`。
