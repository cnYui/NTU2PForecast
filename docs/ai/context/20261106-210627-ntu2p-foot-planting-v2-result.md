# 落脚融入训练第二版（FH / FHS）：结果

预登记：`20261106-195544-ntu2p-foot-planting-v2-preregistration.md`。H-val seed0 × 10000 step，EMA 终点；评价 ode0 不加落脚规划。

- **迈步没有恢复**：步数 0.92 / 0.95，比 BR 不加规划（1.39）还少；摆动监督只把步数提高了 0.03。站立占比仍远高于 GT。

## 目视（`subjval/footloss2_s0/videos/`，GT | BR | BR+规划 | FH | FHS）

- #010 走开：FH、FHS 的脚印轨迹仍是连续的细线（脚慢速挪动），不像 BR + 规划那样一脚一脚分开的点，也不像 GT 有明显的迈步；滑行帧比下降是因为脚的速度和骨盆不再一致（更慢），而不是真的着地迈步。该例 FH .201、FHS .197（BR .175）。
- #028 推人：FH .162、FHS .159，明显好于 BR .201。
- #194 跟随：.368 / .362，比 BR .333 差。

## 解读

1. 两轮共四个候选说明：仅靠损失，确定性读出（ode0）能学会"脚不跟着骨盆整体平移"，但学不会"按节奏抬脚、落地"。原因与四肢摆动偏少、"手没碰到就躲"相同：ode0 输出接近各种可能未来的平均，迈步的时机被平均掉，损失只能把平均后的脚压慢，压不出离散的步子。滑行帧比这个指标在这种"慢挪"下会低估问题。
2. 高噪声段的落脚项对精度友好（FHS 精度与 BR 持平），说明"只在有相位信息的地方约束"的思路本身是对的，问题在读出。
3. 可能的下一步（未做）：
   - 用随机读出（从带温度的噪声出发），让单个样本自己决定迈步时机，再配合这些落脚损失；之前 τ = 0.3 时精度会变差 1.7–2.1%，需要重新权衡；
   - 显式的步态相位变量：模型先预测每只脚的着地/摆动时刻（离散事件），再生成动作。
4. 主线不变，仍为 BR + 落脚规划层；不调权重重跑。
